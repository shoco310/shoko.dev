# 政策調査レポート（作業中）

このディレクトリは、shoko.devの4つの政策（教育・仕事・子育て・行政）について、宇部市の公式資料・市民アンケート・既存事業を調査した記録です。

## ⚠️ このディレクトリの位置づけ

**これは調査中の作業ドキュメントであり、確定した政策文章ではありません。** サイト（`src/`配下）の政策ページの文章・デザインは、このドキュメントの内容によって自動的に変更されるものではなく、内容を人がレビューした上で別途実装作業を行います。

このディレクトリの内容は、追加調査が進むたびに更新されます。矛盾する記述や、後の調査で覆る記述が残っている可能性があります。**サイトへの反映前に、必ず一次資料を人の目で再確認してください。**

## 情報の信頼度の見分け方

各ファイル内で、以下の凡例を使って情報の確度を区別しています。

| 記号 | 意味 |
|---|---|
| ✅ | **一次資料で確認済み**：宇部市・国・県等が発行した計画書・統計・調査報告書そのものを、テキスト抽出または直接閲覧して確認したもの。ページ番号を付記している。 |
| ⚠️ | **部分確認**：地元紙報道など、一次資料に基づく二次情報。または一次資料ではあるが、要件・調査年・対象範囲に注意が必要なもの（例：市データではなく県データ）。 |
| ❓ | **未確認・データ未公表・追加調査が必要**：今回の調査時間内で確認できなかったもの。推測で数値を補うことはしていない。 |
| ❌ | **リンク切れ・アクセス不可**：検索エンジンが提示したURLにアクセスしたが404等のエラーになったもの。再検索が必要。 |

## 「市民の声」の扱いについて（重要）

このレポートでは、以下の3つを明確に区別しています。

1. **実際に公表された市民の意見**（アンケートの自由記述、パブリックコメントで提出された意見など）
2. **調査結果から推測されるニーズ**（アンケートの選択式回答の集計から読み取れる傾向）
3. **議員・行政職員の発言**（これは「市民の声」としては扱っていません）

高校生議会・若者会議のように、市民（生徒）が参加する場であっても、そこでの発言は「市民参加の実施例」として既存制度・ISSUESの文脈で扱い、VOICEセクション（市民の声）には含めていません。
