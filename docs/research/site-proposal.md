## 1. 既存サイトとの関係

現在の政策詳細ページ（`src/pages/PolicyDetail.tsx`）は、すでに以下の構成になっています。

1. HERO（写真・番号・タイトル・タグライン）
2. 政策の背景と目指す姿
3. 具体的な取り組み（5項目）
4. 宇部市の現状と課題
5. 既存制度と改善を検討する点
6. 関連資料・出典（現在は「今後更新します」という断り書きのみ）

ご指定の **HERO / DATA / VOICE / ISSUES / ACTION / SOURCES** という構成に合わせると、既存の②〜⑤を再編し、③をDATA相当、④をISSUES相当、②の一部の実施策部分をACTIONとして独立させ、SOURCESを実データで置き換える形になります。文章そのものは変更せず、**見出しとセクション構成、そしてSOURCESの中身だけを更新する**想定です。

## 2. セクションごとの提案

### HERO
現状維持。写真・番号・タイトル・タグライン。

### DATA — 数字で見る宇部
ご提示いただいたモックアップでは、大きな数字を点線枠で強調する「統計カード」形式が使われています。この形式を採用する場合、**出典のない数値は使わない**という制約から、政策ごとに掲載できる内容量に差が出ます。

**（2026-09-27更新：poppler/pymupdf導入後の一次資料確認により、掲載可能なデータが大幅に増加）**

| 政策 | 掲載できる確認済みデータ | 出典 |
|---|---|---|
| 教育 | 不登校児童生徒数：**令和5年度388人（過去最高）**。就学援助認定率：小学校17.84%・中学校19.75%（約5〜6人に1人） | ✅こども計画 p.22, 29 |
| 仕事 | 高校生の市外進学希望7割超のうち「宇部市に希望する就職先がない」が転出理由の最多回答。企業の6割超が正社員「不足」 | ✅人口ビジョン改訂版 p.32-50 |
| 子育て | 15-39歳市民の6割が「子どもを持ちたい」。学童保育クラブ満足度74%（n=1,116、回答率47.1%） | ✅人口ビジョン改訂版 p.56／学童保育アンケート |
| 行政 | 人口ビジョン改訂パブリックコメント：**意見提出0件**。総合戦略も**1件のみ** | ✅パブコメ実施結果ページ |

上記はいずれも一次資料（宇部市自身の計画書・調査PDF）の本文から直接確認したデータであり、DATAセクションの主力コンテンツとして自信を持って使用できる。ただし、5項目中1〜2項目に集中しており、**教育のIT教育・キャリア教育、仕事のシニア雇用実績、子育ての待機児童数、行政のマイナンバー交付率**などは依然としてデータが薄い（[summary.md](./summary.md)のB表参照）。

**提案：** DATAセクションは「確認済みの数値が1件以上ある場合のみ統計カードを表示し、ない場合はカード自体を出さずに次のセクションに進む」設計とする。数を無理に埋めるための意味のないグラフ（例：出典のない円グラフ）は使わない。

**表示形式の提案：**
- 大きな数字＋単位＋一言説明＋出典（年・出典名）を1枚のカードに収める（モックアップの「調査結果」枠と同じ位置づけ）。
- 複数年のデータがある場合（例：教育の不登校児童数、人口の合計特殊出生率）は、簡易な棒グラフ・折れ線グラフで推移を見せる。ただし軸や単位を省略しない。
- 出典は必ずカードの下に小さく明記する（例：「出典：宇部市教育委員会公表データ（宇部日報デジタル報道、2024年3月）」）。

### VOICE — 市民の声
**提案：** 「公表された市民・当事者の意見」と「調査結果から推測されるニーズ」を明確に区別して表示する（例：見出しの右に「公表された意見」／「アンケートから見えるニーズ」の小さなラベルを出し分ける）。

**（2026-09-27更新）** 一次資料の精読により、自信を持って掲載できる声が大幅に増えた：
- 教育：❓引き続き薄い（こどもの生活実態調査の原本が404で未確認）
- 仕事：✅高校生・大学生アンケートの「住まないつもり」理由（「宇部市に希望する就職先がないから」）、企業アンケートの人材不足の声
- 子育て：✅学童保育クラブ利用者アンケート（満足度・児童本人の声、n=1,116）、こども・若者アンケート（15-39歳、子どもを持つことへの考え・結婚意向）
- 行政：✅パブリックコメントの実際の意見と市の回答（1件のみだが、内容・回答区分まで確認済み）
- 公共交通：❓引き続き出典未特定（掲載を見送るべき）

**提案：** VOICEに載せる意見は、一次資料で発言内容を確認できたものに限定する。教育・公共交通のように出典が未特定・薄い声は、サイトには載せず、内部の調査メモにとどめる。

**議員・行政の発言は市民の声として扱わない**というご指示に従い、高校生議会での質疑応答も「市民（生徒）参加の実施例」としてISSUES/既存制度側で扱い、VOICEには入れない。

### ISSUES — 解決すべき課題
既存制度が対応している範囲と、利用者が直面している障壁を分けて記載する、というご指示通り、現状の「既存制度と改善を検討する点」の構成をほぼそのまま活かせる。

**提案フォーマット：**
- 「対応できていること」（既存制度の一覧）
- 「まだ対応できていないこと」（未解決の課題）
の2カラムまたは2ブロックで対比させる。

### ACTION — 具体的な政策
現行の5つの取り組み項目をそのまま使用。**ただし、今回の調査で根拠が確認できなかった項目（大半）については、文言を「検討します」「調査を進めます」のような、事実確認前を前提にしたトーンに近づけることを検討可能**（今回は文章自体の書き換えは行っていません）。

### SOURCES — 出典・参考資料
現在の「このページの内容は…確認が取れ次第追記していきます」という断り書きを、実際の出典リストに置き換える。

**提案フォーマット：**
- 出典タイトル（リンク）
- 発行主体／調査年
- 「一次資料」「報道」「他自治体事例」などの種別ラベル

各政策ページのSOURCESには、対応する調査レポート（`docs/research/*.md`）に列挙した出典をそのまま反映できる。

## 3. データ可視化に関する提案（過剰な演出を避ける）

- **大きな数字のカード**：出典が明確な単一の数値（例：不登校児童数、DX補助金の採択件数）に限定して使用。
- **時系列の推移グラフ**：3時点以上のデータが揃っている場合のみ使用（例：人口推移、合計特殊出生率）。2時点しかない場合は「前後比較」の数字カードにとどめ、グラフ化しない（誤解を招く傾きの強調を避けるため）。
- **地区別の比較地図・表**：今回、地区別データ（22地区区分）の存在は確認できたが、政策分野別の地区差データまでは確認できていない。裏付けが取れるまでは実装しない。
- 上記のいずれも、**確認できていない政策（教育のIT教育、仕事のシニア雇用、子育ての女性再就職など）については、無理に数字を作らず、DATAセクション自体を簡略化する**（「現在、市の公表データを確認中です」という一文にとどめるなど）。

## 4. 実装しない場合の理由（重要）

STEP6のご指示通り、今回は上記の提案をコードに反映していません。理由は以下の通りです。

1. 主要な一次資料（人口ビジョン・こども計画のPDF）を人の目でまだ確認できていないため、DATAセクションの数値に誤りが混入するリスクがある。
2. VOICEセクションに載せられる「出典が明確な市民の声」がまだ少なく、政策によっては掲載する声がほぼゼロになる。
3. 教育・仕事・子育ての一部項目（IT教育、キャリア教育、生涯学習、シニア雇用、リスキリング、女性再就職支援など）は、現状データが決定的に不足しており、サイトに掲載する情報量が政策間で大きく偏ってしまう。

この調査レポートと掲載案をご確認いただいた上で、（1）不足しているデータの追加調査を続けるか、（2）現時点で確認できた範囲だけで先に実装を進めるか、方針をご指示ください。
