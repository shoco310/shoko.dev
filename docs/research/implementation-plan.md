ダウンロード済みの回答PDF（`kaitou.pdf`）をPythonで再抽出し、`repr()`で一字一句確認しました。

```
意見：宇部市専用の通貨を作ってはどうでしょうか？
それで、条件はいろいろ必要でしょうが、多くの市民に毎月付与される。
当然市内での経済活動でのみ使用可能とし、そのことによって市民になることへのインセンティブに
もなるし、市外への人口流出をも防ぐ。
財源については、様々な補助金の分をまとめてこの「宇部市専用通貨」に費やす、というのはどうで
しょうか？

市の考え方：いただいた御意見は、今後の施策検討の参考とさせていただきます。（区分C）
```

これはPDF内の行送り（改行）をそのまま文章としてつなげたもので、語句の変更・要約は行っていません。**これ以外にパブリックコメントの個別意見内容を引用できる一次資料は今回確認できていない**ため、掲載する引用文はこの1件のみとします。

## 5. デザイン方針

- 配色は既存のビビッドピンク（#FF1680）・白・黒を維持
- DATA：白背景に大きな数字＋ピンクのアクセント、出典を小さく併記

- ACTIONラベル：「既存制度の拡充」＝ピンクのバッジ、「既存制度との関係を確認中」＝グレーのバッジ
- PC・スマートフォンともに、テーブル形式のデータは横スクロール可能なコンテナに収める
