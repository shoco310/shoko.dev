## 2. ページ構成（共通レイアウト案）

```
HERO      既存のまま（写真・番号・タイトル・タグライン）
DATA      数字で見る宇部　※確認済みデータが無い政策・項目は非表示
VOICE     市民の声　→「公表された意見」と「アンケート集計結果」を必ず別ブロックで表示
ISSUES    解決すべき課題　→「確認された事実」「そこから考えられる課題（推測）」「未実施の分析」を3段で区別
ACTION    具体的な取り組み（既存の5項目のまま）　→ 各項目に「既存制度の拡充」「新規提案」のラベルを付記
SOURCES   出典一覧　→ 一次資料／報道／他自治体事例のラベル付き
```

**VOICEの表示ルール（重要）**：選択式アンケートの集計結果（%、人数）は、棒グラフや数値表示で「集計結果」として見せる。**個人の発言のような引用符（「」）や吹き出しのUIには絶対に変換しない。** 引用符付きの発言として載せてよいのは、パブリックコメントのように実際に個人が書いた文章そのものがある場合のみ（今回確認できたのは行政分野の1件のみ）。
